## Key Observations

- Transfer types observed: Control (0x02) = 46 packets, Interrupt (0x01) = 4 packets
- Endpoint usage: EP0 OUT (0x00) = 14, EP0 IN (0x80) = 32, EP1 IN (0x81) = 4
- No bulk transfers on EP1 OUT (0x01) or EP2 IN (0x82) -- device is not streaming
- Traffic is entirely USB housekeeping: descriptor queries, hub port status, link power management
- The kernel periodically queries GET DESCRIPTOR (DEVICE, CONFIGURATION)
- Hub port 8 gets GET_STATUS / SET_FEATURE / CLEAR_FEATURE for link power management (U1/U2)
- Device 2:2 (a USB hub) also appears in the trace since we capture the whole bus
- No Saleae-specific vendor requests observed (bRequest values are standard USB: 0, 6)
- This confirms the device is in bootloader/idle state with no application-level activity
- The FX3 bootloader firmware is already loaded (device enumerates as Logic Pro 8, not as raw Cypress FX3)
- bcdDevice=0.00 -- may change after application firmware upload
- EP2 IN has bMaxBurst=15 -- this is the high-throughput data endpoint for capture streaming
- EP1 IN/OUT with bMaxBurst=0 -- likely used for control/command traffic
